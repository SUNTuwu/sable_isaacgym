# Sable 脚尖 IK 动作编辑

主文件：`sable_motion_edit.blend`。双击 `OPEN_EDITOR.cmd` 打开并启用本地 IK；当前 Blender 已启用。整个目录必须一起保留。无需 SSH 或远程服务器。

## 控制器

四个可选目标 `IK_FL / IK_FR / IK_HL / IK_HR` 分别对应左前、右前、左后、右后。**目标位于终端胶囊最远端的脚尖**，包含半球端帽的半径；不是脚面中心、踝轴或投影到地面的点。位置随脚和后踝旋转。求解使用与控制器完全相同的脚尖位置。

在右侧 `N → Sable IK` 面板选择动作，选择脚尖控制器，按 `G` 移动，然后给 Location/位置插入关键帧，或点击“记录选中控制器”。按空格播放。**所有脚尖轨迹直接打在 `IK_FL / IK_FR / IK_HL / IK_HR` 自身的 Location 通道上，数值就是世界坐标**，没有运动父物体或第二层偏移。

源轨迹保留完整 50 Hz 数据。上一轮先精简到每周期 5 个位置关键帧；经过你的手动修改与本次首尾同步，**目前每只脚每周期有 4–6 个位置关键帧（含首尾）**。保留你修改后的中间关键姿势，曲线仍可用 Bezier 手柄调整。每段之后另有保持／切换键，不计入周期。时间轴仅显示选中对象的键，避免隐藏的高频骨骼／源轨迹键混入。

右后脚 `IK_HR` 在上一轮减帧时从隐藏的 `PATH_HR` 原始脚尖轨迹恢复；本次同步以你随后手工修改的曲线为准。上一轮 5 键拟合误差记录在 `validation_five_keys.json`，它不是当前手调动作的误差上限。直接移动 IK 控制器再记录位置键即可精修，也可以在 Graph Editor 调整 Bezier 手柄。

本次镜像／同步前的完整场景保存在 `backups/before_authored_sync_20261027_160659.blend`；同步结果见 `validation_authored_sync.json`。更早的减帧备份和报告也保留在目录中。

后退 walk 每秒约后移 0.159 m，前进 trot 每秒约前移 0.149 m。它们保留源动作的小幅侧移和偏航：每周期分别约 −0.30°、−2.45°，不能把数据标成精确的零横移／零偏航。训练纯直行任务时，目标速度奖励应允许策略修正这些偏差，而不是强锁根参考。

## 让一个策略同时掌握两种步态

建议继续使用现有 16 维命令和 6 帧历史。`vx` 控制前后方向，`gait_frequency` 控制步频，`phase_fr / phase_hl / phase_hr` 与 `stance_fraction` 描述接触时序；由上层的 walk／trot 选择映射成这些命令，不必另外增加一个输入维度。部署动作仍是 15 个电机目标。当前 Blender 导出与策略的关节数组顺序不同，训练导入必须按 `joint_names` 映射，不能直接复制位置相同的列。

我们的相位约定是 `[FL, FR, HL, HR]`、`phase_i = phi + delta_i`，三个命令是后面三条腿相对左前腿的偏移。对角 trot 可用 `[phase_fr, phase_hl, phase_hr] = [0.5, 0.5, 0]`。原迁移文档中的四拍 walk 候选为 `[0.5, 0.25, 0.75]`；倒放会反转落足顺序，对应候选 `[0.5, 0.75, 0.25]`。这些只是启动候选，必须根据最终手调片段的真实接触事件重新标定；相位零点和支撑比例也要一起对齐。**不能把 WTW 的三个内部步态参数直接当作我们的三个相对腿相位。**

建议的训练顺序：

1. 先统一修整四个参考：前进 walk、后退 walk、前进 trot、后退 trot。检查首尾姿态及速度、足底接触、滑移、关节范围，并按实际周期计算频率与速度标签。标签中的接触点使用碰撞几何，不以脚尖高度单独判定着地。
2. 从现有基础策略继续训练，按四种条件分组采样，初期保持姿态命令和步频在参考附近。每组都使用正确的方向、步态命令与相位；随机采样参考相位初始化，避免只学会从一帧起步。保留旧前进组的训练比例和独立回归评估，防止遗忘。
3. 使用 PPO 的速度跟随、稳定、滑移和电机约束奖励，加上较软的姿态／足端／接触时序参考奖励。动画里的实际关节角 `q_ref` 不是已验证的 PD 目标或教师动作；不要直接当动作监督。保持当前直接电机目标策略接口，不必重新把动画逐帧强加到控制输出。
4. 四组稳定后，扩大速度范围，并在重叠速度区同时训练 walk 和 trot，让同一速度也能按命令选步态。逐步降低精确姿态模仿，保留速度跟随与可调步态时序。按“方向 × 步态”分别报告成功率、跟踪误差、真实相位、滑移和电机峰值，不能只看总平均奖励。
5. 专门加入 walk↔trot 和前进↔停止↔后退的切换课程。相位按圆周连续过渡，频率用正值持续积分，换方向主要改变速度命令；起步、制动和换相过程都需要训练。切换初期可用约 1–2 个周期作为过渡窗口，这是工程初值而非固定要求。之后扩展噪声、延迟、推扰和地形。
6. 先让同一个低层策略可靠执行人为指定的步态，再由上层根据速度、稳定裕度、能耗或宠物情绪选择这些命令。若某个条件长期学不动，再训练该条件的专项教师并蒸馏回来；不需要一开始就维护四个部署策略。

依据：[Walk These Ways 论文与项目](https://gmargo11.github.io/walk-these-ways/)用一个条件化策略实现多种可调步态；[官方 play.py](https://github.com/Improbable-AI/walk-these-ways/blob/master/scripts/play.py)展示速度、步频和步态参数分别输入。上述 Sable 相位表示和训练安排是针对本项目的建议，不是原样照搬 WTW。

若后续改用 [AMP](https://xbpeng.github.io/projects/AMP/index.html)，混合动作库能提供运动风格先验，但“库里同时有 walk 和 trot”不等于策略一定能按命令分别执行。需要让风格条件在策略和模仿目标中一致，并检查各步态是否被保留；这两种基础步态目前优先用已有相位命令即可。

## 重定向与约束

- 原有 19 骨骼及刚体绑定保留；15 个独立执行关节。只用关节本来的旋转轴，不使用任意三轴弯曲。
- 对源机器人读取 URDF 肩／髋 pitch 关节位置，将脚点到该关节的相对向量按前、后腿长度分别缩放，再映射到 Sable 的肩／髋位置；不复制其他机器人的关节角。
- 保留原有限位、固定前腕、后髋 `q_right = -q_left` 约束；腰 roll 参与求解。
- 初次重定向按胶囊支撑位置求得姿态。按用户修正，保持这些姿态不变，把控制器和 IK 几何点一并迁移到真实脚尖。原始未达目标及修正前文件保存在 `backups/`。
- 脚尖与足底最低点是不同量。当前编辑器不自动施加地面碰撞或动力学约束；拖动脚尖后需检查整只胶囊是否穿地。
- 数据集草稿只完成几何重定向；滑步、质心稳定、碰撞、接触力和电机能力仍要在仿真中验证。间隔是保持和切换，不是可直接训练的过渡。
